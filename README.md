# EduGen AI Studio 🎓

An interactive educational studio for teachers and educators to instantly generate worksheets, slide presentations, and lesson plans with customizable AI themes, prompt-driven creators, templates gallery, and high-contrast light/dark modes.

## ✨ Features

- **📝 A4 Worksheet Generator**: Build printable English grammar, reading comprehension, vocabulary, and dialogue exercises customized by CEFR level (A1–C1) with answer keys.
- **📽️ PowerPoint / Slide Deck Creator**: Generate structured classroom presentation outlines, topic overviews, discussion questions, and speaker notes.
- **🎨 Glassmorphic Theme Toggle**: Seamless switching between immersive Deep Dark mode and High-Contrast Light mode with responsive frosted glass styling.
- **📚 Templates Gallery**: Ready-to-use lesson templates for common English teaching units (*Present Perfect vs Past Simple*, *Business Email Etiquette*, *Speaking Exams*, *Phonics*, *Tech Innovation*).
- **💾 Local Library Persistence**: Auto-saves generated lessons and worksheets to browser storage (`localStorage`) for quick access and reuse.

## 🚀 How to Run the Web Version

1. Open `app/src/main/assets/index.html` (or `index.html`) directly in any modern web browser (Chrome, Edge, Safari, Firefox).
2. Alternatively, deploy the `index.html` file to **GitHub Pages**, **Vercel**, or **Netlify** for instant web hosting.

## 📱 Android App Setup

This repository is also configured as an Android Studio project using Kotlin, Jetpack Compose, and Material 3.

To build and run on Android:
1. Open the repository root in **Android Studio**.
2. Sync Gradle files.
3. Run on an Android device or emulator (Android 8.0 / API 26+).
